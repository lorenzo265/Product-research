# Brazilian public and semi-public data sources for an automated opportunity-finding harness

> **How these facts were checked (2026-09-24).** The sandbox egress proxy blocked every direct request to the sources themselves. That covered `*.gov.br`, `queridodiario.ok.org.br`, `pncp.gov.br`, `api.bcb.gov.br`, `apisidra.ibge.gov.br`, `portal.api.gupy.io`, `api.mercadolibre.com`, `reclameaqui.com.br` and `developers.google.com`, which all returned HTTP 403 at CONNECT. The session's WebSearch budget was also used up. **No API below was called live from here.** "Liveness" instead comes from dated third-party evidence: repositories and code updated in 2026 that call these endpoints, READMEs that record live checks with dates, and PyPI release dates. All of it was read on 2026-09-24 through GitHub code search, `raw.githubusercontent.com` and `pypi.org`. Before building any collector, re-run a one-call smoke test per API from an unrestricted network.
>
> Lens key: (1) low software penetration vs sector size · (2) expensive and disliked incumbent · (3) fragmentation · (4) regulatory shock with a deadline · (5) manual work at scale (job postings) · (6) quantified inefficiency · (8) new AI capability · (9) platform ecosystem gaps · (10) manual service already bought on freelance marketplaces · (11) declared pain with money attached.

## Q1. Government and open data (Querido Diário, DOU, CNPJ, IBGE SIDRA, CAGED/RAIS, PNCP, Portal da Transparência, BCB, agency regulatory agendas)

### Takeaway
Almost every government source can be reached with an official, free API or bulk download. None of them needs scraping except the DOU search page, and INLABS is an official alternative for that. The best sources for the harness are CNPJ bulk data plus IBGE CEMPRE for bottom-up counts (lenses 1 and 3), PNCP for public-sector demand with money attached, including the annual procurement plans (lenses 11 and 4), Querido Diário and DOU for regulatory shocks and municipal purchases (lens 4), and CAGED/RAIS through Base dos Dados for occupation-level labour counts (lens 5). The open-source MCP server `mcp-brasil` already wraps most of these.

### Cited Findings

#### Querido Diário (municipal official gazettes, Open Knowledge Brasil)
- Canonical API base `https://api.queridodiario.ok.org.br` with endpoints `/gazettes` and `/cities`. Default page size is 10 and the maximum is 100. `mcp-brasil` lists 20 state capitals as "confirmed coverage". — [mcp-brasil 0.14.0 source, `mcp_brasil/data/diario_oficial/constants.py`](https://pypi.org/project/mcp-brasil/0.14.0/)
- The API needs no authentication. Its rate limit is about 60 req/min, described as "soft, not enforced". — [SmartLic STORY-255](https://github.com/tjsasakifln/SmartLic/blob/HEAD/docs/stories/STORY-255-querido-diario-adapter.md); [brazil-visible, does-estaduais.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/diarios-oficiais/does-estaduais.md)
- **Coverage figures conflict:** "~1,047 municipalities (full-text)" per [SmartLic STORY-255](https://github.com/tjsasakifln/SmartLic/blob/HEAD/docs/stories/STORY-255-querido-diario-adapter.md); "350+ municipalities (of 5,570)" per [SmartLic research, 2026-04-23](https://github.com/tjsasakifln/SmartLic/blob/HEAD/docs/research/2026-04-23-crawling-licitacoes-arquitetura.md); "370+ municipalities" per [brazil-visible](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/diarios-oficiais/does-estaduais.md); "5,000+ cities" per the [mcp-brasil README](https://github.com/Mcp-Brasil/mcp-brasil). The 5,000+ figure contradicts mcp-brasil's own list of 20 confirmed capitals.
- The API reports a coverage "level" per city. One 2026 project selects only "level 3" cities because their history in the API is stable. — [lchampz/apura, "08 - Municípios Selecionados"](https://github.com/lchampz/apura)
- The content is gazette text, not structured procurement data. NLP is needed to pull out tenders. — [SmartLic research, 2026-04-23](https://github.com/tjsasakifln/SmartLic/blob/HEAD/docs/research/2026-04-23-fontes-externas-licitacoes.md)
- The scraper repository is active (1,392 stars, updated 2026-09-23). The API repository was updated 2026-09-12. The official Python wrapper `querido-diario-api-wrapper` was last updated 2025-12-23, and there is an R wrapper (`katerine-dev/queridodiario`). — GitHub repository search, 2026-09-24: [okfn-brasil/querido-diario](https://github.com/okfn-brasil/querido-diario), [querido-diario-api](https://github.com/okfn-brasil/querido-diario-api), [querido-diario-api-wrapper](https://github.com/okfn-brasil/querido-diario-api-wrapper)

#### Diário Oficial da União (Imprensa Nacional)
- INLABS gives free access to the complete DOU editions as PDF and XML, and has done since 2020-01-01. Imprensa Nacional publishes official Bash and Python download scripts. — [Imprensa-Nacional/inlabs README](https://github.com/Imprensa-Nacional/inlabs)
- Those scripts log in with email and password (`POST https://inlabs.in.gov.br/logar.php`), so a free user account is needed. — [inlabs-auto-download-xml.sh](https://github.com/Imprensa-Nacional/inlabs/blob/master/public/bash/inlabs-auto-download-xml.sh). **This conflicts with** [brazil-visible dou.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/diarios-oficiais/dou.md), which says INLABS "requires institutional registration and approval, not open to the general public".
- Full-text search goes through `https://www.in.gov.br/consulta/-/buscar/dou` with `q`, `s` (section do1/do2/do3/doe), `exactDate`, `publishFrom` and `publishTo`. `mcp-brasil` reads the JSON embedded in the result HTML (script id `_br_com_seatecnologia_in_buscadou_BuscaDouPortlet_params`). This is effectively scraping. — [mcp-brasil 0.14.0, `diario_oficial/client_dou.py`](https://pypi.org/project/mcp-brasil/0.14.0/); [brazil-visible dou.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/diarios-oficiais/dou.md)
- The DOU is mostly free text. Extra editions come out without notice, and one edition can hold thousands of acts. — [brazil-visible dou.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/diarios-oficiais/dou.md)
- Ro-DOU, built by the Ministério da Gestão e da Inovação, clips the DOU and municipal gazettes (through Querido Diário) by keyword and sends email, Slack or Discord alerts. — [gestaogovbr/Ro-dou](https://github.com/gestaogovbr/Ro-dou)

#### Receita Federal CNPJ open data
- Bulk ZIP/CSV at `https://arquivos.receitafederal.gov.br/dados/cnpj/dados_abertos_cnpj/`. No authentication. CSVs have no header, use `;` as separator and are Latin-1 encoded. Files are split into `Empresas0-9`, `Estabelecimentos0-9` and `Socios`, plus lookups (`Cnaes`, `Municipios`, `Naturezas`, etc.) and `Simples.zip` (Simples Nacional/MEI option). — [brazil-visible cnpj-completa.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/receita-federal/cnpj-completa.md); [estabelecimentos.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/receita-federal/estabelecimentos.md)
- The data is published monthly and is also listed on dados.gov.br. The dataset has "more than 60 million records". Converting it to SQLite takes about 60 GB free disk and produces a ~30 GB `cnpj.db`. — [rictom/cnpj-sqlite README](https://github.com/rictom/cnpj-sqlite)
- **Format change in August 2026:** in the sócios CSVs, `cnpj_cpf_socio` now carries only the 8-digit CNPJ root when the partner is a company. — [rictom/cnpj-sqlite README](https://github.com/rictom/cnpj-sqlite)
- Fields useful for market sizing: `porte_empresa` (00 not informed, 01 micro, 03 EPP, 05 other) in Empresas; `cnae_fiscal`, `cnae_fiscal_secundaria`, municipality, situação cadastral and start date in Estabelecimentos. "~57 million CNPJs." — [brazil-visible cnpj-completa.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/receita-federal/cnpj-completa.md)
- Known issues: only the latest snapshot is kept (no history), 30–60 day lag, layout changes without notice, and alphanumeric CNPJs from July 2026 that break validators expecting 14 digits. — [brazil-visible cnpj-completa.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/receita-federal/cnpj-completa.md); alphanumeric CNPJ under IN RFB 2.229/2024 per [alanpcf/brasil-data-mcp](https://github.com/alanpcf/brasil-data-mcp)
- Estabelecimentos includes phone and email. Sócios includes partner names. — [brazil-visible estabelecimentos.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/receita-federal/estabelecimentos.md)
- Single-CNPJ lookups: BrasilAPI's terms ask users "not to use automated forms of crawling"; volume should look like "a real person requesting data". — [BrasilAPI README, Termos de Uso](https://github.com/BrasilAPI/BrasilAPI)
- Tooling: `rictom/cnpj-sqlite` (v0.7, March 2026, download based on `caiopizzol/cnpj-data-pipeline`); `cuducos/minha-receita` (moved to codeberg.org/cuducos/minha-receita); ETL repositories updated in September 2026 (`msantosjader/rfb-cnpj-etl`, `bAlemar/Extracao_CNPJ`). — [rictom/cnpj-sqlite](https://github.com/rictom/cnpj-sqlite); [minha-receita](https://github.com/cuducos/minha-receita); GitHub search, 2026-09-24

#### IBGE (SIDRA / API de Agregados / CNAE)
- Endpoints: `https://servicodados.ibge.gov.br/api/v3/agregados` (agregados), `/api/v2/cnae` (CNAE classes), `/api/v1/localidades`, and the classic `https://apisidra.ibge.gov.br/values/...`. — [mcp-brasil 0.14.0, `ibge/constants.py`](https://pypi.org/project/mcp-brasil/0.14.0/); [brazil-visible pib-municipal.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/ibge-estatisticas/pib-municipal.md)
- **Query-size limit conflict:** a live call "revealed a current limit of 50,000 values, although the help page still mentions 100,000". SIDRA does not paginate. — [radar-economico-brasil, docs/data-sources.md](https://github.com/matheuscorreiafranca/radar-economico-brasil/blob/HEAD/docs/data-sources.md)
- CEMPRE 2024 (Cadastro Central de Empresas) tables **9509** (municipal totals) and **9528** (by CNAE section) give local units, companies, employed persons and wages per municipality through API de Agregados v3. — [MatheusFran/dashboard-araguari-uninter README](https://github.com/MatheusFran/dashboard-araguari-uninter)
- IBGE data is open with attribution, and commercial use is allowed for almost all datasets. — [mcp-brasil SOURCES.md §8.1](https://github.com/Mcp-Brasil/mcp-brasil/blob/main/SOURCES.md)
- Libraries: `sidrapy` 0.1.4 (last release 2022-09-19); `ibge` 0.0.5 (2019); `geobr` 2.1.1 (2026-09-23). — [PyPI sidrapy](https://pypi.org/project/sidrapy/), [PyPI ibge](https://pypi.org/project/ibge/), [PyPI geobr](https://pypi.org/project/geobr/)

#### CAGED / RAIS (PDET, Ministério do Trabalho)
- Novo CAGED: monthly microdata (`CAGEDMOV/CAGEDFOR/CAGEDEXC_AAAAMM.txt`) at `ftp://ftp.mtps.gov.br/pdet/microdados/NOVO CAGED/`, published about 30 days after the reference month. No authentication. Includes CNAE, CBO occupation, salary and municipality. **Public microdata has no employer CNPJ.** Figures are preliminary and revised, and the FTP is unstable. — [brazil-visible caged.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/trabalho-emprego/caged.md)
- RAIS: annual files at `ftp://ftp.mtps.gov.br/pdet/microdados/RAIS/`, about 5–15 GB compressed per year, published 1–2 years late. There is no REST API, and the layout changes between years. — [brazil-visible rais.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/trabalho-emprego/rais.md). brazil-visible also says "the CNPJ is available" in public RAIS. **That claim is suspect.** The same site says public CAGED has no CNPJ, and it is not confirmed here. Treat it as unverified.
- Base dos Dados hosts `br_me_rais` and `br_me_caged` on BigQuery. Access needs a Google Cloud project; the free tier covers 1 TB of queries per month, and large tables (RAIS, CNPJ) can use that up. — [brazil-visible base-dos-dados.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/portais-centrais/base-dos-dados.md); [basedosdados/sdk README](https://github.com/basedosdados/sdk); `basedosdados` 2.0.3 released 2026-04-06 ([PyPI](https://pypi.org/project/basedosdados/))

#### PNCP (Portal Nacional de Contratações Públicas, Lei 14.133/2021)
- Public consultation API `https://pncp.gov.br/api/consulta/v1` (OpenAPI at `/api/consulta/v3/api-docs`). Endpoints: `/contratacoes/publicacao`, `/contratacoes/proposta` (open for bids), `/contratacoes/atualizacao`, `/contratos`, `/atas`, `/pca` (Plano de Contratações Anual), `/fornecedores`. Maximum page size is 50 for contratações and 500 for contratos/atas. Modality codes 1–19 (6 = Pregão Eletrônico). — [mcp-brasil 0.14.0, `compras/pncp/constants.py`](https://pypi.org/project/mcp-brasil/0.14.0/)
- No authentication. Periods longer than 365 days get HTTP 422. The portal also has a search API (full-text/faceted search of editais, atas and contratos), per-item results (winning supplier and homologated values) and document downloads. — [AnxietyLab/pncp-cli README](https://github.com/AnxietyLab/pncp-cli)
- `mcp-brasil` rates PNCP as low risk: publication is mandatory under Lei 14.133/21. — [mcp-brasil SOURCES.md](https://github.com/Mcp-Brasil/mcp-brasil/blob/main/SOURCES.md)
- Tooling (evidence of 2026 liveness): `pncp-cli` (stdlib only, NDJSON streaming, checkpointing, includes a Claude Code skill; repository updated 2026-09-18); `pypncp` (async client with a "preços homologados" pipeline; updated 2026-09-15); PyPI `pncp` 0.1.1 (2025-07); `@licinexusbr/mcp` (18 tools, PNCP + CNPJ, no key; 78 stars, updated 2026-09-15). — [pncp-cli](https://github.com/AnxietyLab/pncp-cli); [pypncp](https://github.com/gabrielgz0/pypncp); [PyPI pncp](https://pypi.org/project/pncp/); [Licinexus/licinexus-mcp](https://github.com/Licinexus/licinexus-mcp)

#### Portal da Transparência (CGU)
- `https://api.portaldatransparencia.gov.br/api-de-dados`. Needs a free key, obtained by registering an email at `portaldatransparencia.gov.br/api-de-dados/cadastrar-email` and sent in the `chave-api-dados` header. Unauthenticated requests are blocked. — [brazil-visible portal-transparencia.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/portais-centrais/portal-transparencia.md); [mcp-brasil 0.14.0, `transparencia/constants.py`](https://pypi.org/project/mcp-brasil/0.14.0/)
- Rate limit: 90 req/min per token from 06:00 to 24:00 and 300 req/min from 00:00 to 06:00. Going over returns HTTP 429. — [brazil-visible contratos-federais.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/transparencia-cgu/contratos-federais.md). This is corroborated by mcp-brasil's client ("80 req/min — conservative margin below the 90 req/min daytime limit"): [mcp-brasil 0.14.0, `transparencia/client.py`](https://pypi.org/project/mcp-brasil/0.14.0/)
- Data includes federal contracts by CNPJ, spending, licitações, emendas, sanction lists (CEIS/CNEP/CEPIM), payment cards and fiscal waivers. Commercial reuse is allowed with attribution. CPFs of civil servants are masked at source. — [mcp-brasil SOURCES.md §6.1](https://github.com/Mcp-Brasil/mcp-brasil/blob/main/SOURCES.md); [brazil-visible servidores-federais.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/transparencia-cgu/servidores-federais.md)

#### Banco Central (SGS and Olinda OData)
- SGS: `https://api.bcb.gov.br/dados/serie/bcdata.sgs.{code}/dados?formato=json`. No authentication. **Since March 2025, JSON/CSV queries are limited to 10-year windows**; use `/dados/ultimos/{N}` or split the range. The rate limit is undocumented, and about 5 req/s is recommended. — [brazil-visible sgs-juros.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/banco-central/sgs-juros.md)
- Olinda OData services: PTAX, Expectativas (Focus), TaxaJuros, MercadoImobiliario, IFDATA. — [python-bcb README](https://github.com/wilsonfreitas/python-bcb); `python-bcb` 0.4.0 released 2026-06-15 ([PyPI](https://pypi.org/project/python-bcb/)); `sgs` 3.0.0 (2025-03) ([PyPI](https://pypi.org/project/sgs/))

#### Regulatory agencies (ANVISA, ANS, ANEEL, others) and regulatory agendas
- Lei 13.848/2019 (the general law on regulatory agencies) has a section titled "Do Plano Estratégico, do Plano de Gestão Anual e da Agenda Regulatória". Every federal agency (ANEEL, ANP, Anatel, ANVISA, ANS, ANA, Antaq, ANTT, Ancine, Anac, ANM, and since Lei 15.352/2026 the ANPD) therefore has to publish an Agenda Regulatória. — [Lei 13.848/2019 (Planalto)](https://www.planalto.gov.br/ccivil_03/_ato2019-2022/2019/lei/l13848.htm), text as captured in [emidio-trancoso/advocacia-aberta](https://github.com/emidio-trancoso/advocacia-aberta)
- ANVISA Portal de APIs (`api.anvisa.gov.br`, "Consultas Externas"). **Verified live 2026-09-06 and 2026-09-08 by a third party.** OAuth2 client credentials come from a gov.br login, and each token lasts 1,740 s. Rate limit is a token bucket (burst 25, refill 1/s) keyed by source IP. Cloudflare returns 403 to curl's default User-Agent. Data covers the petition **analysis queue ("fila de análise")**, medical-device UDI, GMDN terms and petition subjects with legal basis and fees. 35 documented endpoints return 404 ("documented, not deployed"). The same datasets exist as bulk CSV at `dados.anvisa.gov.br/dados/CONSULTAS/`, refreshed on weekdays. Python package `anvisa` 0.4.0 (2026-09-08). — [vasfvitor/anvisa-api](https://github.com/vasfvitor/anvisa-api); [PyPI anvisa](https://pypi.org/project/anvisa/)
- ANVISA also runs a reverse-engineered Bulário API at `consultas.anvisa.gov.br/api/consulta/bulario`, which `mcp-brasil` calls at 1 req/s. — [mcp-brasil 0.14.0, `anvisa/constants.py`](https://pypi.org/project/mcp-brasil/0.14.0/)
- ANEEL: CKAN at `https://dadosabertos.aneel.gov.br/api/3/action/`, no authentication, 32,000 records per query, and resource IDs change on update. — [brazil-visible aneel.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/agencias-reguladoras/aneel.md)
- ANS: CKAN at `https://dadosabertos.ans.gov.br/api/3/action/`, no authentication, monthly updates (operators, beneficiaries). — [brazil-visible ans.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/outros/ans.md)
- Health data (DataSUS, immunisation) is rated **critical risk**. The reasons given are LGPD art. 11 §4 (sensitive data may not be shared for economic advantage) and some datasets being CC BY-ND (no derivatives). — [mcp-brasil SOURCES.md §1](https://github.com/Mcp-Brasil/mcp-brasil/blob/main/SOURCES.md)

#### dados.gov.br (federal catalogue)
- The current API is `https://dados.gov.br/dados/api/publico/conjuntos-dados`. **The sources disagree on authentication:** mcp-brasil's client sends the header `chave-api-dados-abertos` ([mcp-brasil 0.14.0, `dados_gov_br/constants.py`](https://pypi.org/project/mcp-brasil/0.14.0/)), while brazil-visible says no authentication is needed and notes the legacy CKAN `/api/3/action/` "may still work" ([brazil-visible portal-dados-abertos.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/portais-centrais/portal-dados-abertos.md)).
- It returns metadata only, not data. Links are often broken and quality is uneven. — [brazil-visible portal-dados-abertos.md](https://github.com/nferdica/brazil-visible/blob/main/docs/apis/portais-centrais/portal-dados-abertos.md)

#### LGPD and legal framing (applies to all sources)
- LGPD art. 7 §3: processing of publicly accessible personal data must respect the purpose, good faith and public interest that justified making it available. §4: consent is waived for data made manifestly public by the data subject. §7: further processing for new purposes is allowed if the purposes are legitimate and specific and the data subject's rights are preserved. — [Lei 13.709/2018 (Planalto)](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709.htm). This text was cited from knowledge of the statute; the page could not be re-fetched this session.
- mcp-brasil's per-source risk summary rates Transparência, IBGE, BCB, Legislativo and PNCP as low risk; saúde as critical; eleitoral and judicial (DataJud: Res. CNJ 331/2020 and 446/2022 prohibit large-scale redistribution) as high. — [mcp-brasil SOURCES.md](https://github.com/Mcp-Brasil/mcp-brasil/blob/main/SOURCES.md)

## Q2. Demand and pain signals (Reclame Aqui, Google Places, job platforms, freelance marketplaces, Mercado Livre, YouTube)

### Takeaway
Private demand-signal sources are much more closed than the government ones. Mercado Livre closed its public search to external apps in 2025–2026, and LinkedIn and Vagas.com.br explicitly block AI crawlers. Reclame Aqui has no public API and sits behind Cloudflare. The workable options are the YouTube Data API (cheap comment reads), 99Freelas (server-rendered pages, permissive robots.txt), Gupy company career pages and Programathor/Empregare job data, Catho through its sitemap, consumidor.gov.br open complaint data (a legal proxy for Reclame Aqui), and Google Places only for small targeted samples.

### Cited Findings

#### Reclame Aqui
- No official public API was found. At least 37 public code files call an undocumented internal JSON API at `iosearch.reclameaqui.com.br/raichu-io-site-search-v1/...`: company search, `query/companyComplains/{n}/{offset}?company={id}`, and `complains/?company=...`. — GitHub code search, 2026-09-24, e.g. [pumba-dev/reclame-aqui-web-scrapping](https://github.com/pumba-dev/reclame-aqui-web-scrapping), [peuvini/reclame-aqui-scraper](https://github.com/peuvini/reclame-aqui-scraper), [zeroc00I/reclame_aqui_scrapper](https://github.com/zeroc00I/reclame_aqui_scrapper)
- Scrapers hit Cloudflare. One 2026 project saw HTTP 403 from around offset 490. It reported that Google Colab IPs are "immediately recognized and blocked by Cloudflare", so it needed Playwright run locally. — [meurii/churn-intelligence, notebooks/fase1b_scraping.ipynb](https://github.com/meurii/churn-intelligence)
- Legal alternative: consumidor.gov.br publishes open-data CSVs (`;`-delimited) of **finished complaints**, which a 2026 collector aggregates. — [danzeroum/juridico-platform, services/ingest/tasks/consumidor_gov.py](https://github.com/danzeroum/juridico-platform). Other descriptions: "monthly, anonymized, excellent for text analysis" per [giovanebarcelos/datasets-big-data](https://github.com/giovanebarcelos/datasets-big-data); Sindec (PROCON) host "does not resolve" per [plataforma-inteligencia-combustiveis-docs, mapa-de-integracoes.md](https://github.com/joaopaulomirandamatias/plataforma-inteligencia-combustiveis-docs). mcp-brasil's `mj` feature reaches PROCONs/Sindec datasets through the MJSP CKAN ([mcp-brasil README](https://github.com/Mcp-Brasil/mcp-brasil)).

#### Google Maps / Places API
- Requesting the `reviews` field puts a call into the **Place Details Enterprise + Atmosphere** SKU. That SKU has about 1,000 free calls per month, then about US$25 per 1,000. The API returns **at most 5 reviews per place**. Several 2026 codebases cite Google's pricing page for this. — [Sve-nnN/dr-angulo-website, src/lib/google-reviews.ts](https://github.com/Sve-nnN/dr-angulo-website); [Dodivar/watch-ecommerce, documentation/google-reviews/README.md](https://github.com/Dodivar/watch-ecommerce); [thill1/LordsGym, GOOGLE_REVIEWS_SETUP.md](https://github.com/thill1/LordsGym); [modfx-media/houston-cool-pools](https://github.com/modfx-media/houston-cool-pools)
- Google bills by the highest SKU tier requested, not by number of fields. — [cablate/mcp-google-map, docs/research-ai-place-selection.md](https://github.com/cablate/mcp-google-map)
- Official client: `google-maps-places` 0.9.0 (2026-06-03). The legacy `googlemaps` 4.10.0 dates from 2023. — [PyPI google-maps-places](https://pypi.org/project/google-maps-places/), [PyPI googlemaps](https://pypi.org/project/googlemaps/)

#### Job platforms
Robots.txt evidence was reviewed on 2026-08-08 by [Atroci/br-skill, references/carreira-scanner-br.md](https://github.com/Atroci/br-skill/blob/main/references/carreira-scanner-br.md):
- **Gupy:** each company's page `https://<empresa>.gupy.io/` is server-rendered, with every open job embedded in `__NEXT_DATA__` (title, department, city/state, workplace type; no publication date in the listing). `portal.gupy.io` has a permissive robots.txt, and `www.gupy.io` explicitly allows ClaudeBot, GPTBot and PerplexityBot. Separately, 44 public code files call the undocumented aggregated endpoint `https://portal.api.gupy.io/api/v1/jobs?jobName=...&limit=&offset=` (e.g. [pdroacordi/candidatus-jobs](https://github.com/pdroacordi/candidatus-jobs), [danielrochamaia/gupy-jobs-scraper](https://github.com/danielrochamaia/gupy-jobs-scraper); GitHub code search, 2026-09-24). Gupy's own terms of use were not reviewed.
- **Vagas.com.br:** `schema.org/JobPosting` JSON-LD exists, but robots.txt has a **named full block** (`Disallow: /`) for ClaudeBot, Claude-Web, anthropic-ai, GPTBot, CCBot, PerplexityBot and others.
- **Catho:** `Disallow: /buscar/vagas/` (search), but `/vagas-emprego/...` pages are mostly allowed. Discovery works through `sitemap-index.xml`. AI bots (GPTBot, Claude-Web, anthropic-ai...) are explicitly allowed.
- **LinkedIn:** robots.txt forbids "any automation without express permission" and names AI bots. Classified as "excluded — never implement".
- **Indeed Brasil:** robots.txt is relatively permissive with no named AI block. Its terms of use were not reviewed.
- **InfoJobs:** the job detail route (`/detailvacancy.aspx`) is disallowed.
- **Programathor:** JSON-LD `JobPosting` with `datePosted`/`validThrough`; permissive robots.txt.
- **Empregare:** documented public API `GET /api/{culture}/vagas/buscar-novo` ("does not require authentication") plus an **official MCP server at `/api/mcp`**. Its robots.txt allows `/api/mcp` and `/api/docs` but not the search endpoint directly.

#### Freelance marketplaces
Evidence reviewed on 2026-08-08 by [Atroci/br-skill, references/propostas-scanner-br.md](https://github.com/Atroci/br-skill/blob/main/references/propostas-scanner-br.md):
- **99Freelas:** plain server-rendered HTML. The listing is at `/projects?q=` and each project has a details table (`info-adicionais`). Robots.txt is permissive: `/projects` and `/project/<id>` are allowed, and only `/termos/`, `/privacidade/`, `/faq/` and similar are disallowed. There are also several older community scrapers ([TinyHero13/webscraping-api-dashboard-99freelas](https://github.com/TinyHero13/webscraping-api-dashboard-99freelas), [blmarquess/web-crawlers](https://github.com/blmarquess/web-crawlers)).
- **Workana:** the `/jobs` listing is rendered client-side. Robots.txt only disallows `/api/`, login/signup parameters and `?ag=1`. Collection would need browser-assisted reading.
- **GetNinjas:** customer requests are **private** and routed to subscribing professionals, so there is no public list of open jobs. Category pages carry marketing data in `__NEXT_DATA__`, including `averagePrices`. Robots.txt is `Allow: /`, blocking `/pros/*`, `/usuarios` and pagination parameters.
- **Upwork:** a Cloudflare challenge blocked even reading robots.txt. **Fiverr:** `Disallow: /search/`, `/gigs/search`, `/pro/*`. **Freelancer.com.br:** the `/projetos` listing sits behind a Cloudflare challenge. **Freelans:** robots.txt explicitly allows ClaudeBot and GPTBot, but there were no active opportunities at the time of checking.

#### Mercado Livre API
- `GET api.mercadolibre.com/sites/MLB/search` returns **"403 forbidden, always. Endpoint deprecated for external apps"**. `GET /items/{id}` for another seller's item returns 403 `access_denied`. OAuth client-credentials tokens only unlock the product catalogue, metadata (categories, **trends**, listing types) and the app's own account. HTML scraping is blocked from datacenter IPs. Status recorded on 2026-05-25. — [victornoleto/carros, curva-docs/context/mercadolivre-status.md](https://github.com/victornoleto/carros/blob/master/curva-docs/context/mercadolivre-status.md)
- On 2026-07-16 a developer got 200 on `/users/me` with a valid OAuth token but 403 on `/sites/MLB/search`. They asked Mercado Livre about app whitelisting or certification. — [investidor18economia/Teilor-MIA, docs/mercadolivre-developer-escalation-403.md](https://github.com/investidor18economia/Teilor-MIA/blob/master/docs/mercadolivre-developer-escalation-403.md)
- Another 2026 project reports 403 "for all queries, even with browser headers… cannot be bypassed without an OAuth2 access token". — [gustavobarrosss/task-promozone, DECISOES_TECNICAS.md](https://github.com/gustavobarrosss/task-promozone)

#### YouTube Data API v3
- Default quota is 10,000 units per day per Google Cloud project, resetting at midnight Pacific. `search.list` costs 100 units; `commentThreads.list`, `videos.list` and `channels.list` cost 1 unit. Going over returns 403 `quotaExceeded`. — [airbytehq/airbyte, source-youtube-data/AGENTS.md](https://github.com/airbytehq/airbyte/blob/HEAD/airbyte-integrations/connectors/source-youtube-data/AGENTS.md)
- A single source describes a **"granular quota system (June 2026)"**. Under it, `search.list` has its own bucket of 100 calls per day and other reads draw 1 unit from the shared 10,000. — [AgriciDaniel/youtube-scout, scripts/scout.py](https://github.com/AgriciDaniel/youtube-scout/blob/main/scripts/scout.py). Not corroborated.
- Libraries: `google-api-python-client` 2.200.0 (2026-09-01). `youtube-comment-downloader` 0.1.83 (2026-07-30) works "without using the YouTube API". — [PyPI google-api-python-client](https://pypi.org/project/google-api-python-client/), [PyPI youtube-comment-downloader](https://pypi.org/project/youtube-comment-downloader/)

## Q4. Existing open-source tools, libraries and MCP servers wrapping these sources

### Takeaway
One active MCP server, `mcp-brasil`, already covers most government sources the harness needs: Querido Diário, DOU, PNCP, Portal da Transparência, IBGE, BCB, ANVISA, ANEEL, dados.gov.br, CNES and more. It has 1,786 stars, was updated 2026-09-23, and has 70 features, 533 tools and a per-source licence file. The harness should adopt it for ad-hoc agent lookups and write its own deterministic Python collectors only for high-volume, recurring pulls: CNPJ counts, PNCP, Querido Diário/INLABS, 99Freelas, Gupy, YouTube comments and consumidor.gov.br.

### Cited Findings
- **mcp-brasil** (`Mcp-Brasil/mcp-brasil`): "MCP Server for 70 Brazilian public data sources", with 533 tools, 131 resources and 102 prompts. Install with `claude mcp add mcp-brasil -- uvx --from mcp-brasil python -m mcp_brasil.server`. ### Inferences
- **Adopt mcp-brasil** as the ad-hoc query layer for researchers and verifiers (D-001 in `docs/01-arquitetura.md` favours Claude Code plus scripts). Pin a GitHub commit rather than the lagging PyPI release. Keep its LGPD PII switch off.
- **Write own collectors** where the harness needs time series, deduplication and fact provenance (`fatos.jsonl`), which an MCP call does not give: (1) CNPJ monthly counts by CNAE × porte × municipality, (2) PNCP contratações and PCA (reuse `pncp-cli`), (3) Querido Diário keyword watch plus INLABS DOU XML, (4) CAGED/RAIS aggregates via Base dos Dados SQL, (5) 99Freelas daily projects, (6) Gupy job pages, (7) YouTube comment threads on seeded channels, (8) consumidor.gov.br monthly complaints, (9) ANVISA queue snapshots.
- **Web search only:** Reclame Aqui, app marketplaces, agency Agendas Regulatórias, Workana/GetNinjas/Indeed, Catho (pending ToS).
- **Avoid:** LinkedIn, Vagas.com.br, Upwork/Fiverr scraping, Mercado Livre scraping, bulk Google reviews, and DataSUS or other health microdata.
- `pncp-cli`'s built-in Claude Code skill and `mcp-brasil`'s `SOURCES.md` are directly reusable as templates for the harness's own source registry (licence, risk, attribution per source).

### Gaps
- mcp-brasil's GitHub source code (newer than 0.14.0) was not inspected. Its `ACCEPTABLE_USE.md` was downloaded but not reviewed in detail.
- No MCP server was found for Querido Diário alone, for CAGED/RAIS, for Reclame Aqui, for the freelance marketplaces, or for the app marketplaces.
- Maintenance quality (tests, issue backlog) of the smaller MCP servers was not assessed. mcp-brasil had 33 open issues on 2026-09-24.
